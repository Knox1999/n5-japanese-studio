HOW TO USE
----------
STEP 1
Upload this ZIP's contents to the ROOT of your GitHub repository.
Choose Replace for existing files.

Commit:
  Fix V50 deployment and add repository cleanup

This commit will automatically trigger the normal deployment.
The previous error should be gone.

STEP 2
After the deployment is GREEN:
GitHub -> Actions -> One-time Repository Cleanup -> Run workflow -> Run workflow.

The cleanup action will commit the deletion automatically.
It then deletes its own workflow file too.

STEP 3
A second normal Pages deployment will automatically run because cleanup
creates one commit. Wait until that deployment is GREEN.
