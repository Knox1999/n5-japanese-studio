VOICE / EMOTION V49
-------------------
Existing V48 natural voice profile was already stronger than the old robotic voice.
V49 adds context-based delivery:
- Dialogue / shadowing → warmer `jf_tebukuro`
- Vocabulary / grammar / spelling → clearer `jf_alpha`
- Reading / neutral sentence → blended `jf_alpha,jf_tebukuro`
- questions, exclamation, politeness, shadowing get different pacing/pause timing
- profile version changed to force cached old audio regeneration
- browser fallback still ranks the best installed Japanese neural/natural voice

Important:
Kokoro is an offline neural TTS engine; it does not expose full actor-style emotion controls.
V49 therefore improves naturalness through voice selection + contextual pacing + pauses.
For true cinematic emotional acting later, a dedicated expressive cloud TTS can be added as an optional provider.
