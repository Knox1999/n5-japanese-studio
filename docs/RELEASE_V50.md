# V50 Production Release

V50 consolidates the current production identity as **The Nihongo Vibes**.

Key production features include deep-linkable lesson views, PWA branding, V50 cache management, GA4 learning events, backup/restore, role-play conversation, reading vocabulary, natural Japanese neural audio, Kanji KLC, and lesson mastery testing.

The old V41–V49 root-level reports and setup packages are historical artifacts and are intentionally removed by the one-time cleanup workflow. Git history preserves them if they are ever needed.
