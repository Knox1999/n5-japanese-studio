GITHUB PAGES VERSION — বাংলা Setup
===================================

এখন আর:
- localhost লাগবে না
- same Wi-Fi লাগবে না
- Windows Firewall লাগবে না
- PC server চালু রাখতে হবে না

একবার GitHub Pages-এ publish করলে যেকোনো জায়গা থেকে phone/PC browser দিয়ে URL খুলতে পারবেন।

PUBLISH
-------
1) GitHub-এ New repository তৈরি করুন
2) Repository name: n5-japanese-studio
3) Public select করুন
4) Create repository
5) এই ZIP Extract করুন
6) Extract করা folder-এর ভিতরের সব file/folder repository-তে upload করুন
7) Commit changes
8) Settings → Pages
9) Source → GitHub Actions
10) Save/enable করুন

Included workflow automatically deploy করবে।

PHONE
-----
Site URL Chrome/Safari-তে খুলুন।

Android:
Menu → Add to Home screen / Install app

iPhone:
Safari → Share → Add to Home Screen

তাহলে app icon-এর মতো home screen থেকে খুলতে পারবেন।
